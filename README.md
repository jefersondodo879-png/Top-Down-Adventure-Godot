# Top Down Adventure Godot

Repositorio de trabalho para integrar a versao organizada do projeto com:

- 496 RPG Icons
- Boss Minotauro
- Boss Mantis

## Arquivos de entrada
Envie para a pasta `input/` os seguintes ZIPs, mantendo estes nomes:

- `Top_Down_Adventure_V1_8_3.zip`
- `496_RPG_icons.zip`
- `mino_v1.1_free(1).zip`
- `Animated insect enemy assets(1).zip`

Ao enviar os quatro arquivos, o GitHub Actions executara o workflow `Build Godot Project` e gerara um artefato ZIP para download.
